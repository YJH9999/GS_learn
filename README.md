# GS_learn · 高等数学知识库

一个纯静态、离线可用的高等数学复习知识库（对应 **同济大学《高等数学》第八版**，上册 1-7 章 + 下册 8-12 章），布局延续 [XD_learn 线性代数知识库](https://github.com/YJH9999/XD_learn)。

## ✨ 功能

- **知识库（index.html）**
  - 十二章 + 总览/附录，全部知识点按"定义 / 易错点 / 高频考点"打标签
  - **每章末附「题库视角」小节**：由站内 4285 道题按知识点统计出的「高频考点表（含题量）/ 常见思路清单 / 易错清单」，可直接当复习优先级地图用
  - 全文搜索（Ctrl K）、目录筛选、知识点收藏（localStorage）
  - 冲刺模式：只看定义 / 易错点 / 高频考点 / 例题
  - **导出 PDF / HTML**：顶栏「导出」把当前节（1.1、1.2…）、当前章或全册导出，格式面板二选一：**打印 / 另存 PDF**（A4 排版、公式不跨页、证明与解答自动展开、宽表格自动折行）或**下载 HTML 文件**（站点样式内联的单文件，双击即可看）；侧栏每章、每节右侧也有快捷导出按钮
  - 站点图标 favicon（蓝灰地球）全站统一
  - 浅色 / 深色主题，移动端适配，阅读进度自动记忆
  - 本地 KaTeX 渲染，公式离线可用

- **备考中心（exam.html）**
  - **题库 4285 题**：判断 360 / 选择 938 / 填空 876 / 计算 1687 / 证明 424，覆盖全部 12 章（含从吉米多维奇与教材习题中重新归类出的选择题、填空题）
  - 题目来源：校内**单元小测**（第一～五、七～十、十二单元，含官方答案）、**教材习题**（同济第八版**全十二章**全部习题与总习题，逐页视觉转录，共 992 题）、**吉米多维奇精选**（张天德版精解**全十二章 1336 题**，逐页视觉转录）、**教材经典**、**真题改编**（江南大学 2016–2020 高数 I(1) / I(2) 期末卷题型，分别标注为「2016–2020高数I(1)期末真题改编」「2016–2020高数I(2)期末真题改编」）
  - 期末结构组卷模拟（选择 5×4′ + 填空 5×4′ + 计算 5×10′ + 证明 1×10′）、**章节可多选**、智能判分、错题本、试卷导出 PDF

## 👤 账号与学习数据

- **个人中心**（右上角头像）：昵称、头像（点头像上传图片，首次设置时可挑 emoji / 纯色）、使用时长、做题数、错题数、正确率
- **首次引导**：第一次进入先看到 GitHub 登录卡（可「暂不登录」跳过），登录成功后才设头像昵称；若账号里已有资料（换设备）会直接带过来，不再重复设置。登录卡里的说明折叠收纳：令牌怎么建、**令牌只在创建那一屏显示一次（GitHub 之后只有 Regenerate，无法再查看原值，所以生成后要立刻存好）**、换设备为什么不用新建 / 不用 Regenerate、什么时候才真的要重新生成、多设备与退出登录的规则都在里面
- **跨设备同步**：粘贴 GitHub 令牌（只需 Gists 读写权限）后，错题本、收藏、统计、试卷记录写进你账号下的私有 Gist；三个站共用一次登录，换设备自动拉回；未登录时进入备考中心会再提示一次
- **试卷记录**：每次组卷自动留档（题目、作答、分数、用时），可继续作答 / 回看卷面 / 重做 / 删除
- **线上 / 离线二选一**：组完卷先选作答方式——线上直接答题自动判分；离线打印卷子手写（空白卷或含答案版都能打），做完拍照或导入 PDF 交回
- **离线时长折算**：上传离线作答后，按该卷考试用时的 60%（按题型估算总时长）一次性计入本站学习时长，同一份卷只计一次
- **离线附件**：记录里带照片 / PDF，图片随账号同步，PDF 超过 700KB 时原件只留在本机
- **导出**：作答记录、错题本、空白卷、含答案卷都能导出为 PDF（浏览器打印 → 另存为）；打印前会等 KaTeX 字体全部就绪，公式不会缺字
- **字号加减**：顶栏 A− / A+ 全站缩放 85%–130%，三站共用

## 🚀 使用

静态站点需通过 HTTP 访问（直接双击 index.html 无法加载正文）：

```bash
cd GS
python -m http.server 8000
# 浏览器打开 http://localhost:8000
```

或直接访问 GitHub Pages（若已开启）。
