# GS_learn · 高等数学知识库

一个纯静态、离线可用的高等数学复习知识库（对应 **同济大学《高等数学》第八版**，上册 1-7 章 + 下册 8-12 章），布局延续 [XD_learn 线性代数知识库](https://github.com/YJH9999/XD_learn)。

## ✨ 功能

- **知识库（index.html）**
  - 十二章 + 总览/附录，全部知识点按"定义 / 易错点 / 高频考点"打标签
  - **每章末附「题库视角」小节**：由站内 2730 道题按知识点统计出的「高频考点表（含题量）/ 常见思路清单 / 易错清单」，可直接当复习优先级地图用
  - 全文搜索（Ctrl K）、目录筛选、知识点收藏（localStorage）
  - 冲刺模式：只看定义 / 易错点 / 高频考点 / 例题
  - 浅色 / 深色主题，移动端适配，阅读进度自动记忆
  - 本地 KaTeX 渲染，公式离线可用

- **备考中心（exam.html）**
  - **题库 2730 题**：判断 / 选择 / 填空 / 计算 / 证明五种题型，覆盖全部 12 章
  - 题目来源：校内**单元小测**（第一～五、七～十、十二单元，含官方答案）、**教材习题**（同济第八版**全十二章**全部习题与总习题，逐页视觉转录，共 992 题）、**吉米多维奇精选**（张天德版精解**全十二章 1336 题**，逐页视觉转录）、**教材经典**、**真题改编**（江南大学历年期末卷题型）
  - 期末结构组卷模拟（选择 5×4′ + 填空 5×4′ + 计算 5×10′ + 证明 1×10′）、智能判分、错题本、试卷导出 PDF
  - 考点速览：12 章 × 5 张考点卡片

## 🚀 使用

静态站点需通过 HTTP 访问（直接双击 index.html 无法加载正文）：

```bash
cd GS
python -m http.server 8000
# 浏览器打开 http://localhost:8000
```

或直接访问 GitHub Pages（若已开启）。

## 📁 结构

```
GS/
├── index.html          知识库主页
├── exam.html           备考中心
└── assets/
    ├── content/        15 个章节内容分片（按 manifest 懒加载）

    ├── katex/          本地 KaTeX
    ├── fonts/          字体
    ├── app.js          知识库逻辑（SPA、搜索、冲刺模式）
    ├── exam_app.js     组卷模拟逻辑
    ├── manifest.js     章节 manifest / 标题映射 / 大纲

```
